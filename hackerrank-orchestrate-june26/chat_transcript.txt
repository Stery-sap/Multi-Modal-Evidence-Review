why __pycache__ is created?

[AGENT RESPONSE]
The `__pycache__` directory is automatically created by Python to improve execution performance. Before running your human-readable `.py` files, Python compiles them into intermediate bytecode (stored as `.pyc` files inside `__pycache__`). Saving this bytecode allows Python to load and execute the scripts much faster upon subsequent runs/imports by bypassing compilation overhead.
